# Test-Checkliste nach jedem Update (ca. 10 Minuten, mit dem Testkonto)

Voraussetzung: Testkonto „Test Konto“ (Verwaltung → Mitarbeiter → Schalter „Testkonto“). Es zählt in keiner Statistik
und keiner Rangliste. Telegram-Meldungen zum Testkonto kommen trotzdem an – am Namen erkennbar.

## 1. Stempeln
- [ ] Testkonto eine Schicht für heute geben (Verwaltung → Dienstplan).
- [ ] Am Handy einloggen → Startseite zeigt „Als Nächstes“ mit der Schicht, offenen Aufgaben und ggf. Wissen/Tausch.
- [ ] Kommen per QR am Studio-PC/Tablet → Status „Eingestempelt“.
- [ ] Pause → Pause Ende → Gehen. Unter „Stunden“ steht der Tag richtig (Pause abgezogen).

## 2. Schichttausch
- [ ] Vom eigenen Konto dem Testkonto einen Tausch schicken.
- [ ] Testkonto öffnet die App → Fenster „… möchte mit dir tauschen“ erscheint sofort.
- [ ] „Später“ → Fenster weg; unter Mitteilungen (Glocke) steht die Anfrage mit Knöpfen.
- [ ] Zustimmen → Telegram: Antrag mit Freigabe-Knöpfen. Freigeben → Dienstplan zeigt den Tausch.

## 3. Urlaub
- [ ] Testkonto beantragt 2 Tage Urlaub (Konto → Urlaub beantragen).
- [ ] Leitung stimmt zu → Dominik gibt frei → Tage im Dienstplan, Resturlaub sinkt.

## 4. Aufgaben
- [ ] Eine Aufgabe mit Fotonachweis erledigen → Telegram mit Foto und Freigabe/Ablehnen.
- [ ] Ablehnen → Aufgabe steht am nächsten Tag wieder drin (mit Foto).

## 5. Wissen
- [ ] Eine Lektion machen → XP steigen, Ring und „% gelernt“ wachsen.
- [ ] Eine Frage absichtlich falsch → Fortschritt bleibt, Frage kommt später zum Wiederholen.

## 6. Verwaltung
- [ ] Freigaben: Abschnitt „Was hängt?“ prüfen und abarbeiten (erscheint nur, wenn etwas liegt).
- [ ] Statistik: Testkonto taucht NICHT auf.
